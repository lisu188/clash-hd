# Source-only cloud checks

Cloud/CI work in this repository is intentionally limited to source code,
documentation, synthetic fixtures generated by tests, and patch metadata.

No archived game screenshots, debugger logs, Ghidra exports, executable-derived
fixture bundles, or retail runtime files are committed under `cloud/`.

Run the public source-only validation entry point with:

```bash
python tools/cloud_check.py --mode cloud
```

Any check requiring `clash95.exe`, Ghidra, CDB, x32dbg, DirectDraw runtime
capture, original assets, saves, or a visible game session is a **local**
validation task. Its raw evidence must remain outside public source control.
