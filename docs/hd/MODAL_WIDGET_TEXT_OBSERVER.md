# Widget quantity-text observations

`tools/modal_widgets_text_observer.py` prepares three disabled, read-only
breakpoints for the actual widgets-v1 candidate: entry to its inherited quantity
adapter, entry to the native formatter for that call, and return to the native
caller. Its schema is `clash95_modal_widgets_text_observer_v1`, protocol
`modal_widgets_text_observation_v1`, and event namespace `MWTEXT`.

The public preparation boundary authenticates the external widget bundle once
through `modal_widgets_context.load_context`. The genuine inherited text
metadata is used to verify the installed CALL, adapter code/tail, caller cleanup,
format string and original native spans in the actual widget executable. The
historical text observer supplies only pinned byte/site/expression helpers;
neither its context nor its logs are relabeled. The new sequence checks retain
their source provenance and leave historical observer files unchanged.

All 36 recipe sources, the authentication dependency, context reader and both
observer modules are snapshotted before and after preparation. The binding
includes the real candidate/stage/resolution/recipe, raw and canonical manifest
hashes, complete source hashes, native sites, occupied breakpoint inventory and
the generated fragment. IDs 150/151/152 are disabled by default. Explicit ID or
address collisions fail, and each command must fit CDB's line bound. Fragment
bytes are ASCII with CRLF endings; changing their transport bytes invalidates
public validation.

The authentic candidate emits MWIDGETS identity/scope, its exact inherited
ARMY scope, and then PTILE identity/scope. These five records must occur once
in that order before the MWTEXT contract and the single ordered
ADAPTER/NATIVE/RETURN triplet. Old-stage success identities, duplicate or
prefixed records, malformed events, source drift and debugger failures remain
failures with their raw lines retained. Header/thread/stack/owner identities,
native and physical dimensions, pixel ranges, argument translations, format,
alignment and signed quantity must agree throughout the call. The adapter
preserves incoming registers and relevant flags. Native return may change
cdecl volatile registers; EBX/ESI/EDI/EBP must be preserved.

## Preparation and evaluation

Supply the complete occupied breakpoint inventory as a JSON object with
canonical decimal IDs mapped to integer VAs. The barracks producer's expanded
inventory is a starting point; a future host must also include its own Lock,
capture and ownership observers before composing the fragment.

```powershell
python -B tools/modal_widgets_text_observer.py --original C:/Clash/clash95.exe --candidate C:/ClashTests/modalwidgets-validation/widget-1024x768.exe --candidate-manifest C:/ClashTests/modalwidgets-validation/widget-1024x768.candidate.json --occupied-breakpoints C:/ClashTests/modalwidgets-validation/occupied-breakpoints.json
```

Preparation prints the packet and never launches a process. Evaluation adds
`--packet`, `--fragment` and `--log` together. It rebuilds the same candidate
context and regenerates the complete packet and exact fragment before reporting
an observed call. Duplicate/nonfinite/deep or otherwise malformed JSON fails
through the strict parser. Failed public admission retains the available raw
log diagnostics and cannot establish source authentication.

`evaluate_sequence` is a pure diagnostic API: its passing result still has
`source_authenticated=false` and `text_call_observed=false`. Public validation
may establish one source-bound call, but `runtime_accepted`, manual proof and
promotion remain false. The surrounding host still needs exact full-command
authentication, checkpoint timing, process/trace/query bindings and cleanup.
This observer does not prove native font pixels, complete barracks composition,
ordinary input, modal exit or healthy map return.

Run its synthetic fixtures with:

```powershell
python -B tools/test_modal_widgets_text_observer.py
```
